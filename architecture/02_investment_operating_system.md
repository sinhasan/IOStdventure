# Investment Operating System

TD Venture IOS is built as a set of business engines.

## Core Engines

1. Identity Engine
2. Profile Intelligence Engine
3. Matching Intelligence Engine
4. Opportunity Engine
5. Timeline Engine
6. Communications Engine
7. Meeting Engine
8. Payment Engine
9. Due Diligence Engine
10. Portfolio Intelligence Engine
11. Knowledge Engine
12. Chief of Staff Engine

## Operating Model

Business Event → Engine → Timeline → Notification → Digital Colleague → Human Escalation when required.

## Rule

Screens are only windows into engines. Business logic lives inside engines.
